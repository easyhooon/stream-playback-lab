# stream-playback-lab

Android Media3 기반 VOD 및 라이브 스트리밍을 학습하기 위한 개인 프로젝트입니다. 프로젝트명은 임시이며, 현재는 계획 단계입니다. 아직 플레이어 구현이나 성능 검증 결과는 없습니다.

서버에서 제공한 MP4를 재생했던 경험을 확장해, 직접 소유하거나 사용 권한이 있는 원본을 다중 비트레이트 HLS로 변환하고 제공하는 흐름을 학습하려 합니다. VOD 환경에서 적응형 비트레이트(ABR), 탐색, 버퍼링, 네트워크 오류 복구를 검증하는 것이 목표입니다.

이후 별도 단계에서 실시간 입력과 인코딩, 계속 갱신되는 플레이리스트, 라이브 엣지(live edge), 지연, 재연결을 실험할 계획입니다. 구체적인 구성과 기능 범위는 실험을 진행하며 정합니다.

초기 실험은 제한된 로컬 테스트 환경에서 진행할 예정이며, 유료 인프라나 실제 개인 데이터는 사용하지 않습니다.
